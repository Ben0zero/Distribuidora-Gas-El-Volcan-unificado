# Distribuidora de Gas El Volcán - Proyecto Unificado

Este repositorio reúne las distintas versiones del proyecto **Distribuidora de Gas El Volcán** para la asignatura **Desarrollo Full Stack II (DSY1104)** de Duoc UC.

## Estructura

- **version-1/** → Versión estática (HTML, CSS, JavaScript). Sitio original con lógica en `localStorage`.
- **version-2/** → Versión React (Vite + React + React Bootstrap + React Router). Avance con catálogo, carrito, login, registro y rutas.
- **documentos/** → Anexos del proyecto (ERS, guías, plan de adaptación y documentación técnica).

## Propósito

Mantener un único repositorio con la evolución del proyecto: desde la entrega 1 (HTML/CSS/JS) hasta las versiones posteriores en React, junto con la documentación de soporte.
